# P0 设计系统

本文档是工业/B2B 商店设计系统的唯一权威说明，梳理令牌、组件和命名规范。

---

## 一、架构

设计系统由三层组成，职责分离：

```
tokens.css      设计令牌（单一事实来源）→ 输出为 :root CSS 变量
  ↓
components.css  语义组件类（引用 token，不硬编码值）
  ↓
app.css         页面级布局样式（历史骨架 + 各页面专属布局）
```

| 文件 | 职责 | 规则 |
|------|------|------|
| `app/styles/tokens.css` | 颜色/字体/字号/圆角/高度/阴影令牌 | 只定义值，不写选择器 |
| `app/styles/components.css` | 可复用组件类（btn/card/badge/table/form/breadcrumb + 导航） | 只引用 token，不硬编码颜色/字号 |
| `app/styles/app.css` | 页面专属布局（collection/product/cart/account/quote/home/footer） | 布局结构，颜色/字号优先引用 token |
| `app/styles/tailwind.css` | Tailwind v4 入口，导入上述文件 | 提供 utility 类 |

> **演进方向**：`app.css` 中的页面样式已大量引用 token，未来可将可复用的部分逐步下沉到 `components.css`。

## 四、命名规范

1. **颜色**：一律用 `var(--color-*)`，禁止硬编码 hex/rgb
2. **字号**：优先用 `var(--type-*)`，特殊场景（hero 大标题）可用 `clamp()`
3. **圆角**：用 `var(--radius-*)`
4. **间距**：用 rem 单位（1rem = 16px 基准）
5. **新增令牌**：先加 tokens.css，再在组件中引用，不直接写值
